# 📝 My Todo App

Aplikasi pengelola tugas harian (To-Do List) yang sederhana, responsif, dan mudah digunakan. Proyek ini dibuat untuk membantu mencatat prioritas harian agar produktivitas tetap terjaga.

## 🚀 Demo
Lihat aplikasi yang sudah live di sini: [https://syaaa16.github.io/todo-app/](https://syaaa16.github.io/todo-app/)

## ✨ Fitur Utama
- **Tambah Tugas:** Menambahkan daftar pekerjaan baru dengan mudah.
- **Hapus Tugas:** Menghapus tugas yang sudah tidak relevan.
- **Tandai Selesai:** Klik pada tugas untuk menandai bahwa tugas tersebut telah selesai.
- **Responsive Design:** Tampilan yang nyaman dilihat baik di laptop maupun di HP.
- **Local Storage:** Tugas kamu tetap tersimpan meskipun halaman di-refresh.

## 🛠️ Teknologi yang Digunakan
- **HTML5:** Struktur utama aplikasi.
- **CSS3:** Styling agar tampilan menarik dan rapi.
- **JavaScript (Vanilla JS):** Logika interaktif untuk menambah dan menghapus tugas.
